# PRODUCT
This project is a game called wordis it is meant to capture the feal of tetris attack 
it is a competetive word building game.

# ORIGIN
this product is built off my personal vue game emplate and contains much of the logic for websockets publishing to steam firebase railway etc.
it also contains a simple tic tac toe game that will be replaced with the real game.

# FLOW
the user will be able to play select between a multiplayer game with friends online or they can choose to play against a bot

# GAMEPLAY
wordis is a real time spelling game with a tug of war scoring system.
letters have points and each word you spell gives you points accordingly
when a player plays a word the points pull to there side accordingly. 
players can earn attacks that they can play against their opponent to make the game harder such as locking letters forcing them to use a letter etc.
